# codegame
Simple game made in python using pyqt6

Game's GUI made by using pyqt6 library There are 2 modes to play: 1 player mode and 2 players mode, both on one computer Rules are simple. The code that you have to guess is 4 digit, without the same digits in it! After every try of guessing, there are hints displaying in a textbox about which number is in the code or not. Also, there are hints if the digit is in the right place or not. On the right side, you can see the logs about every try, for example: 1R 1RP. It means there is 1 right number AND THIS NUMBER IS IN THE RIGHT PLACE. After guessing the code you can see how many attempts it took to guess the code

My best score is guessing the code in 6 attempts! Can you beat me? 🙂 Just download and try, have fun!

The logic of the script is good, I didn't discover any massive bugs or something like this. If you want to fix or add something go ahead.
